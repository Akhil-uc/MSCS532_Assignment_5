# Assignment 5 – Quicksort Algorithm

## Requirements
- Python 3.x

## Run
```bash
python quicksort.py
```
## Summary

This Assignment implements both Deterministic and Randomized Quicksort algorithms in Python. It compares their performance through benchmarking and analyzes their time and space complexities. The results show that while the deterministic version is slightly faster on random inputs, the randomized version provides more consistent performance by reducing the likelihood of worst-case execution.
